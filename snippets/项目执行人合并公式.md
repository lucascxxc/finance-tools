# Sheet1 × Sheet2 项目执行人汇总公式

## 场景与列位

| | 项目列 | 执行人 | 所属部门 | 数据起始 |
|---|---|---|---|---|
| Sheet1 | B 列 | — | — | 第 1 行 |
| Sheet2 | T 列 | A 列 | R 列 | 第 2 行 |

目标：在 Sheet1 输出「执行人（所属部门）」，多人用分号连写，**同一执行人+部门组合只出现一次**。

补充口径：**所属部门为空的执行人照常输出**，只显示姓名、不显示空括号。只有执行人为空的行才跳过。

---

## 方案 A｜推荐（Microsoft 365 / Excel 2021+ / WPS 新版）

放在 Sheet1 的 C1，向下填充：

```excel
=IF($B1="","",IF(COUNTIF(Sheet2!$T$2:$T$5000,$B1)=0,"未匹配",TEXTJOIN("；",TRUE,UNIQUE(FILTER(Sheet2!$A$2:$A$5000&IF(Sheet2!$R$2:$R$5000="","","（"&Sheet2!$R$2:$R$5000&"）"),(Sheet2!$T$2:$T$5000=$B1)*(Sheet2!$A$2:$A$5000<>""),"")))))
```

分段说明：

| 片段 | 作用 |
|---|---|
| `COUNTIF(...)=0` | 匹配校验，找不到就返回「未匹配」，不报错 |
| `FILTER(条件1*条件2, ...)` | 取出该项目的所有「执行人（部门）」，`*` 表示同时满足 |
| `A&IF(R="","","（"&R&"）")` | 拼成目标格式；**部门为空时只留执行人姓名，不产生空括号** |
| `UNIQUE(...)` | 按「执行人+部门」组合去重，只留首次出现 |
| `TEXTJOIN("；",TRUE,...)` | 忽略空值，用中文分号连成一个单元格 |

输出示例：`张三（技术部）；李四（市场部）；王五`

最后一位「王五」在 Sheet2 的 R 列是空的，照常写出来，只是不带括号。

> 去重口径仍是「执行人+部门」整体。若同一个执行人在同一项目下既有填部门的行、又有空白部门的行，会输出两条，例如 `王五（生产部）；王五`。想合并成一条（取有部门的那条），见下方变体。

**变体**

- 想按字母/拼音排序：`SORT(UNIQUE(FILTER(...)))`
- 部门为空也想保留空括号（显示为 `王五（）`）：把 `IF(...)` 换回 `"（"&Sheet2!$R$2:$R$5000&"）"`
- 部门列是公式返回的空格（看起来空但 `IF` 判断失效）：用 `IF(TRIM(Sheet2!$R$2:$R$5000&"")="","",...)`，并把拼接处的 `Sheet2!$R$2:$R$5000` 也换成 `TRIM(Sheet2!$R$2:$R$5000)`
- 同执行人既有带部门行、又有空部门行，只想留带部门那条：下面这条 `LET` 版（需 365 的 `MAP`/`LAMBDA`）

```excel
=IF($B1="","",IF(COUNTIF(Sheet2!$T$2:$T$5000,$B1)=0,"未匹配",LET(a_,Sheet2!$A$2:$A$5000,r_,Sheet2!$R$2:$R$5000,t_,Sheet2!$T$2:$T$5000,f,FILTER(a_,(t_=$B1)*(a_<>""),"x"),g,FILTER(r_,(t_=$B1)*(a_<>""),"x"),k,MAP(f,g,LAMBDA(a,r,IF(r<>"",1,IF(SUM((f=a)*(g<>""))=0,1,0)))),TEXTJOIN("；",TRUE,UNIQUE(FILTER(f&IF(g="","","（"&g&"）"),k=1,""))))))
```

原理：`MAP` 逐行判断——本行有部门就保留；本行没部门，但该执行人在本项目下**不存在**任何带部门的行，才保留。
注意别用 `COUNTIFS` 写这个逻辑，它是聚合函数，在 `FILTER` 的数组参数里不会逐行展开，会整体失效。
- 分隔符想用顿号：把 `"；"` 换成 `"、"`
- B1 是表头、数据从 B2 开始：公式里 `$B1` 改成 `$B2`，公式放 C2

## 模糊匹配升级

适用场景：Sheet1 项目名与 Sheet2 项目名不是完全一致，但有包含 / 重合关系。其他规则（去重、无部门处理、输出格式）一律不变。

### 先看你的例子能不能被简单公式匹配

| | 长度 | 反向搜索 |
|---|---|---|
| Sheet1：SAAS平台系统建设 | 长 | 在「绿地SAAS平台」里找不到 |
| Sheet2：绿地SAAS平台 | 短 | 在「SAAS平台系统建设」里也找不到 |

**两段互不为子串**，所以「任一端是另一端子串」这种最简单模糊会漏。公共部分在「SAAS平台」这 4 个字，藏在 Sheet1 名字中间。下面三个方案由简到稳递进。

### 模糊 v1｜双向子串包含（最简单）

Sheet1 名字是 Sheet2 任一行 T 值的子串，或 Sheet2 任一名字是 Sheet1 名字的子串。

```excel
=IF($B1="","",IF(SUMPRODUCT(((Sheet2!$T$2:$T$5000&"")<>"")*((ISNUMBER(SEARCH($B1,Sheet2!$T$2:$T$5000&"")))+(ISNUMBER(SEARCH(Sheet2!$T$2:$T$5000&"",$B1)))))=0,"未匹配",TEXTJOIN("；",TRUE,UNIQUE(FILTER(Sheet2!$A$2:$A$5000&IF(Sheet2!$R$2:$R$5000="","","（"&Sheet2!$R$2:$R$5000&"）"),((Sheet2!$T$2:$T$5000&"")<>"")*((ISNUMBER(SEARCH($B1,Sheet2!$T$2:$T$5000&"")))+(ISNUMBER(SEARCH(Sheet2!$T$2:$T$5000&"",$B1))))*(Sheet2!$A$2:$A$5000<>""),"")))))
```

SEARCH 在数组里逐行搜索，`(A)+(B)` 表示「任一为真」。 `&""` 把可能为数字的 T 列强制转文本，避免 SEARCH 失败。
**你的例子用这个会返回「未匹配」**——双向都不命中。需要下面 v2。

### 模糊 v2｜自动去后缀（能覆盖你的例子）

把 Sheet1 项目名按"系统建设 / 项目建设 / 系统 / 建设 / 工程"等常见后缀切掉，取主体去 Sheet2 搜。

```excel
=IF($B1="","",LET(q,IFERROR(TEXTBEFORE($B1,"系统建设"),IFERROR(TEXTBEFORE($B1,"项目建设"),IFERROR(TEXTBEFORE($B1,"系统"),IFERROR(TEXTBEFORE($B1,"建设"),IFERROR(TEXTBEFORE($B1,"工程"),$B1))))),IF(q="","",IF(SUMPRODUCT(((Sheet2!$T$2:$T$5000&"")<>"")*ISNUMBER(SEARCH(q,Sheet2!$T$2:$T$5000&"")))=0,"未匹配",TEXTJOIN("；",TRUE,UNIQUE(FILTER(Sheet2!$A$2:$A$5000&IF(Sheet2!$R$2:$R$5000="","","（"&Sheet2!$R$2:$R$5000&"）"),((Sheet2!$T$2:$T$5000&"")<>"")*ISNUMBER(SEARCH(q,Sheet2!$T$2:$T$5000&""))*(Sheet2!$A$2:$A$5000<>""),"")))))))
```

走一遍你的例子：
1. `TEXTBEFORE("SAAS平台系统建设","系统建设")` → `"SAAS平台"`
2. 在 Sheet2 搜 `"SAAS平台"` → `"绿地SAAS平台"` 命中 ✓

要 365 的 `LET` / `TEXTBEFORE`。`IFERROR` 嵌套兜底：切不到后缀时用原名。
**局限**：去后缀靠硬编码关键词清单，遇到没列出的修饰词（「改造」「升级」「二期」等）会失效。需要在公式里继续加 `IFERROR(TEXTBEFORE($B1,"改造"),...)` 之类。详见下方「关键词表扩展示例」。

### 模糊 v3｜人工关键词列（最稳）

Sheet1 加一列 D「查询关键词」，每行手动填简称，公式按 D 列去 Sheet2 模糊搜。

D1 填 `SAAS平台`，D2 填 `智慧园区`，依此类推。C1 公式：

```excel
=IF(OR($B1="",$D1=""),"",IF(SUMPRODUCT(((Sheet2!$T$2:$T$5000&"")<>"")*ISNUMBER(SEARCH($D1,Sheet2!$T$2:$T$5000&"")))=0,"未匹配",TEXTJOIN("；",TRUE,UNIQUE(FILTER(Sheet2!$A$2:$A$5000&IF(Sheet2!$R$2:$R$5000="","","（"&Sheet2!$R$2:$R$5000&"）"),((Sheet2!$T$2:$T$5000&"")<>"")*ISNUMBER(SEARCH($D1,Sheet2!$T$2:$T$5000&""))*(Sheet2!$A$2:$A$5000<>""),"")))))
```

缺点是多一列要维护。**优点是命中精确、可控**。建议在大批量匹配前先用这个跑一次，把结果存成「项目 ↔ 关键词」对照表存成 Sheet 一份，以后再上 v2 自动。

### 关键词表扩展示例（v2 补丁）

按业务常见修饰词继续往 `LET` 里堆 `IFERROR(TEXTBEFORE(...))`：

```excel
LET(q, IFERROR(TEXTBEFORE($B1,"系统建设"),
         IFERROR(TEXTBEFORE($B1,"项目建设"),
          IFERROR(TEXTBEFORE($B1,"改造升级"),
           IFERROR(TEXTBEFORE($B1,"系统"),
            IFERROR(TEXTBEFORE($B1,"建设"),
             IFERROR(TEXTBEFORE($B1,"工程"),
              IFERROR(TEXTBEFORE($B1,"项目"),
               IFERROR(TEXTBEFORE($B1,"改造"),
                IFERROR(TEXTBEFORE($B1,"升级"),
                 IFERROR(TEXTBEFORE($B1,"二期"),
                  IFERROR(TEXTBEFORE($B1,"一期"),$B1)))))))))))),
 ...)
```

按你团队的项目命名习惯增减，**词越长越靠前**（先切「系统建设」再切「系统」，避免先切「系统」把「系统建设」误伤成「建设」）。

## 方案 B｜兼容老版本（Excel 2019，有 TEXTJOIN 无 FILTER/UNIQUE）

**Step 1｜Sheet2 加辅助列**（用 Z 列，Z2 输入后下拉）：

```excel
=IF($T2="","",IF(COUNTIFS($T$2:$T2,$T2,$A$2:$A2,$A2,$R$2:$R2,$R2)=1,$A2&IF($R2="","","（"&$R2&"）"),""))
```

`COUNTIFS` 用「逐行扩张的区域」统计到当前行为止的出现次数，=1 表示首次出现，达到去重效果。
`IF($R2="","",...)` 保证部门为空时只写姓名，不产生空括号。**这里只过滤执行人为空的行，部门为空的行照常参与**——不要把 `$R2=""` 加进外层的 `IF` 判断，否则人就被漏掉了。

**Step 2｜Sheet1 的 C1**（粘贴后按 `Ctrl+Shift+Enter`，花括号出现才算数组公式）：

```excel
=TEXTJOIN("；",TRUE,IF(Sheet2!$T$2:$T$5000=$B1,IF(Sheet2!$Z$2:$Z$5000<>"",Sheet2!$Z$2:$Z$5000,""),""))
```

### 模糊补丁（方案 B 的子串版）

老版本没有 `LET`/`TEXTBEFORE`，模糊策略只能选 **v1 双向子串包含**。把 Step 2 整条换成下面这个（仍要 `Ctrl+Shift+Enter`）：

```excel
=TEXTJOIN("；",TRUE,IF(((Sheet2!$T$2:$T$5000&"")<>"")*((ISNUMBER(SEARCH($B1,Sheet2!$T$2:$T$5000&"")))+(ISNUMBER(SEARCH(Sheet2!$T$2:$T$5000&"",$B1)))),Sheet2!$A$2:$A$5000&IF(Sheet2!$R$2:$R$5000="","","（"&Sheet2!$R$2:$R$5000&"）"),""))
```

辅助列 Z 不再需要。**这个版本对付不了「SAAS平台系统建设 vs 绿地SAAS平台」这种例子**——双向都不为子串。在老版本里要兜这种情况，只能用 VBA（见下）。

## 方案 C｜兜底（Excel 2016 及更早，无 TEXTJOIN）

按 `Alt+F11` → 插入模块，粘贴：

```vba
Function GetExecutors(pItem As Range, pCol As Range, eCol As Range, dCol As Range) As String
    Dim i As Long, s As String, dict As Object, k As String, e As String, d As String, v As Variant
    Set dict = CreateObject("Scripting.Dictionary")
    For i = 1 To pCol.Rows.Count
        If Trim(pCol.Cells(i, 1).Value) = Trim(pItem.Value) Then
            e = Trim(eCol.Cells(i, 1).Value)
            d = Trim(dCol.Cells(i, 1).Value)
            k = e & IIf(d = "", "", "（" & d & "）")
            If e <> "" And Not dict.Exists(k) Then dict.Add k, 1
        End If
    Next i
    For Each v In dict.Keys
        s = IIf(s = "", CStr(v), s & "；" & CStr(v))
    Next v
    GetExecutors = IIf(s = "", "未匹配", s)
End Function
```

只判断执行人 `e` 是否为空，部门 `d` 为空时仍会写入，只是不拼括号。

调用（Sheet1 C1，普通回车即可）：

```excel
=GetExecutors($B1,Sheet2!$T$2:$T$5000,Sheet2!$A$2:$A$5000,Sheet2!$R$2:$R$5000)
```

文件需另存为 `.xlsm`，启用宏。

### 模糊补丁（方案 C）

新增两个函数，覆盖上面 v1 / v2 / v3 的需求：

```vba
' 双向子串包含（对应模糊 v1）
Function GetExecutorsFuzzy(pItem As Range, pCol As Range, eCol As Range, dCol As Range) As String
    Dim i As Long, s As String, dict As Object, k As String, e As String, d As String, v As Variant
    Dim a As String, b As String, hit As Boolean
    Set dict = CreateObject("Scripting.Dictionary")
    a = Trim(pItem.Value)
    If a = "" Then GetExecutorsFuzzy = "": Exit Function
    For i = 1 To pCol.Rows.Count
        b = Trim(pCol.Cells(i, 1).Value)
        hit = (Len(b) > 0) And ((InStr(1, b, a, vbTextCompare) > 0) Or (InStr(1, a, b, vbTextCompare) > 0))
        If hit Then
            e = Trim(eCol.Cells(i, 1).Value)
            d = Trim(dCol.Cells(i, 1).Value)
            k = e & IIf(d = "", "", "（" & d & "）")
            If e <> "" And Not dict.Exists(k) Then dict.Add k, 1
        End If
    Next i
    For Each v In dict.Keys
        s = IIf(s = "", CStr(v), s & "；" & CStr(v))
    Next v
    GetExecutorsFuzzy = IIf(s = "", "未匹配", s)
End Function

' 按关键词搜（对应模糊 v3，最稳）
Function GetExecutorsByKeyword(pKw As Range, pCol As Range, eCol As Range, dCol As Range) As String
    Dim i As Long, s As String, dict As Object, k As String, e As String, d As String, v As Variant
    Dim a As String, b As String
    Set dict = CreateObject("Scripting.Dictionary")
    a = Trim(pKw.Value)
    If a = "" Then GetExecutorsByKeyword = "": Exit Function
    For i = 1 To pCol.Rows.Count
        b = Trim(pCol.Cells(i, 1).Value)
        If Len(b) > 0 And InStr(1, b, a, vbTextCompare) > 0 Then
            e = Trim(eCol.Cells(i, 1).Value)
            d = Trim(dCol.Cells(i, 1).Value)
            k = e & IIf(d = "", "", "（" & d & "）")
            If e <> "" And Not dict.Exists(k) Then dict.Add k, 1
        End If
    Next i
    For Each v In dict.Keys
        s = IIf(s = "", CStr(v), s & "；" & CStr(v))
    Next v
    GetExecutorsByKeyword = IIf(s = "", "未匹配", s)
End Function
```

调用：

```excel
' 双向子串包含
=GetExecutorsFuzzy($B1,Sheet2!$T$2:$T$5000,Sheet2!$A$2:$A$5000,Sheet2!$R$2:$R$5000)
' 按 Sheet1 D 列填的关键词搜
=GetExecutorsByKeyword($D1,Sheet2!$T$2:$T$5000,Sheet2!$A$2:$A$5000,Sheet2!$R$2:$R$5000)
```

**对付「SAAS平台系统建设 vs 绿地SAAS平台」**：`GetExecutorsFuzzy` 也无能为力（双向都不是子串）。建议用 `GetExecutorsByKeyword`，在 Sheet1 的 D 列填 `SAAS平台`。

## 报错与排查

| 现象 | 原因 | 处理 |
|---|---|---|
| `#NAME?` | 版本不支持 TEXTJOIN/FILTER/UNIQUE | 换方案 B 或 C |
| `#VALUE!` | 三个区域行数不一致 | A/R/T 统一到同一结束行 |
| 明明有数据却返回「未匹配」 | 不可见字符或前后空格 | 两边都套 `TRIM(CLEAN(...))`；或项目名一侧是文本一侧是数字，用 `$B1&""` 统一 |
| 结果只有一个人 | Sheet2 里该项目确实只有一条 | 先用 `COUNTIF` 核对条数 |
| 运行卡顿 | 引用了整列 `$T:$T` 参与数组运算 | 收窄到实际数据范围，或转「表格」用结构化引用 |
| 同执行人多部门出现两次 | 去重口径是「执行人+部门」组合 | 若只要执行人唯一，把 UNIQUE 的输入改成只看 A 列，或方案 B 的 COUNTIFS 去掉 R 条件 |
| 无部门的人显示成 `王五（）` | 用的是改版前的旧公式 | 换成上面的 `IF(R="","",...)` 写法 |
| 无部门的人整条消失 | 有人往 FILTER 条件里加了 `R<>""` | 只有 A 列（执行人）需要非空判断，R 列不要加进条件 |
| 部门看着是空却仍带括号 | 单元格里是空格或公式返回的空串 | 判断处改 `IF(TRIM(Sheet2!$R$2:$R$5000&"")="",...)` |
| 同一人输出成 `王五（生产部）；王五` | 该执行人既有带部门行又有空部门行 | 用方案 A 里那条 `LET`+`MAP` 变体合并 |
| 模糊版报 `#NAME?` | 版本不支持 `LET` / `TEXTBEFORE` | 365 才支持；老版用方案 B 模糊补丁或 VBA 的 `GetExecutorsFuzzy` |
| 模糊版无脑命中所有行 | 公式里漏了 T 列非空判断 `&""<>""` | 空 T 行被 SEARCH 当成"空串包含一切"误判命中；补上条件 `((Sheet2!$T$2:$T$5000&"")<>"")` |
| 模糊版用 v1（双向子串）但你的例子仍「未匹配」 | 双向都不为子串 | 改用 v2（自动去后缀）或 v3（人工关键词列） |
| 自动去后缀仍漏 | Sheet1 项目名带清单里没列的修饰词（"改造"/"升级"/"二期"…） | 继续往 LET 里堆 `IFERROR(TEXTBEFORE($B1,"改造"),...)`，**长词在前、短词在后** |
| 模糊匹配搜出不该出的行 | 关键词太短（"平台"/"系统"），命中过宽 | 改用更具体的关键词，或在 v3 关键词列里手动收窄 |

## S3-3｜模糊 v2（自动去后缀，覆盖你的例子）

```excel
=IF($B1="","",LET(q,IFERROR(TEXTBEFORE($B1,"系统建设"),IFERROR(TEXTBEFORE($B1,"项目建设"),IFERROR(TEXTBEFORE($B1,"系统"),IFERROR(TEXTBEFORE($B1,"建设"),IFERROR(TEXTBEFORE($B1,"工程"),$B1))))),IF(q="","",IF(SUMPRODUCT(((Sheet3!$B$2:$B$5000&"")<>"")*ISNUMBER(SEARCH(q,Sheet3!$B$2:$B$5000&"")))=0,"未匹配",TEXTJOIN("；",TRUE,UNIQUE(FILTER(Sheet3!$C$2:$C$5000&IF(Sheet3!$G$2:$G$5000="","","（"&Sheet3!$G$2:$G$5000&"）"),((Sheet3!$B$2:$B$5000&"")<>"")*ISNUMBER(SEARCH(q,Sheet3!$B$2:$B$5000&""))*(Sheet3!$C$2:$C$5000<>""),"")))))))
```

## S3-4｜模糊 v3（人工关键词列，最稳）

Sheet1 的 D 列填关键词（若 D 列已被主公式占用，改到 E 列，公式里 `$D1` 同步改成 `$E1`）：

```excel
=IF(OR($B1="",$D1=""),"",IF(SUMPRODUCT(((Sheet3!$B$2:$B$5000&"")<>"")*ISNUMBER(SEARCH($D1,Sheet3!$B$2:$B$5000&"")))=0,"未匹配",TEXTJOIN("；",TRUE,UNIQUE(FILTER(Sheet3!$C$2:$C$5000&IF(Sheet3!$G$2:$G$5000="","","（"&Sheet3!$G$2:$G$5000&"）"),((Sheet3!$B$2:$B$5000&"")<>"")*ISNUMBER(SEARCH($D1,Sheet3!$B$2:$B$5000&""))*(Sheet3!$C$2:$C$5000<>""),"")))))
```

## S3-5｜同执行人有/无部门合并版（LET + MAP）

```excel
=IF($B1="","",IF(COUNTIF(Sheet3!$B$2:$B$5000,$B1)=0,"未匹配",LET(a_,Sheet3!$C$2:$C$5000,r_,Sheet3!$G$2:$G$5000,t_,Sheet3!$B$2:$B$5000,f,FILTER(a_,(t_=$B1)*(a_<>""),"x"),g,FILTER(r_,(t_=$B1)*(a_<>""),"x"),k,MAP(f,g,LAMBDA(a,r,IF(r<>"",1,IF(SUM((f=a)*(g<>""))=0,1,0)))),TEXTJOIN("；",TRUE,UNIQUE(FILTER(f&IF(g="","","（"&g&"）"),k=1,""))))))
```

## S3-6｜老版本兼容（Excel 2019，有 TEXTJOIN 无 FILTER/UNIQUE）

**Step 1｜在 Sheet3 加辅助列**（用 Z 列，Z2 输入后下拉）：

```excel
=IF($B2="","",IF(COUNTIFS($B$2:$B2,$B2,$C$2:$C2,$C2,$G$2:$G2,$G2)=1,$C2&IF($G2="","","（"&$G2&"）"),""))
```

**Step 2｜Sheet1 的 D1**（`Ctrl+Shift+Enter`，出现花括号才算数组公式）：

```excel
=TEXTJOIN("；",TRUE,IF(Sheet3!$B$2:$B$5000=$B1,IF(Sheet3!$Z$2:$Z$5000<>"",Sheet3!$Z$2:$Z$5000,""),""))
```

**老版本模糊补丁**（双向子串版，辅助列不需要了）：

```excel
=TEXTJOIN("；",TRUE,IF(((Sheet3!$B$2:$B$5000&"")<>"")*((ISNUMBER(SEARCH($B1,Sheet3!$B$2:$B$5000&"")))+(ISNUMBER(SEARCH(Sheet3!$B$2:$B$5000&"",$B1)))),Sheet3!$C$2:$C$5000&IF(Sheet3!$G$2:$G$5000="","","（"&Sheet3!$G$2:$G$5000&"）"),""))
```

## S3-7｜VBA 版（无需改代码，只换参数）

前面方案 C 的三个函数**参数都是 Range，可以复用**，调用时把区域换成 Sheet3 的即可：

```excel
' 精确匹配
=GetExecutors($B1,Sheet3!$B$2:$B$5000,Sheet3!$C$2:$C$5000,Sheet3!$G$2:$G$5000)
' 模糊：双向子串包含
=GetExecutorsFuzzy($B1,Sheet3!$B$2:$B$5000,Sheet3!$C$2:$C$5000,Sheet3!$G$2:$G$5000)
' 模糊：按 Sheet1 D 列关键词搜
=GetExecutorsByKeyword($D1,Sheet3!$B$2:$B$5000,Sheet3!$C$2:$C$5000,Sheet3!$G$2:$G$5000)
```

参数顺序固定为 `（项目单元格, 项目列, 执行人列, 部门列）`，换表只改区域、不改函数。

## S3 专属注意事项

| 项 | 说明 |
|---|---|
| 输出列 | 原版占 C 列的话，新版放 D 列；v3 关键词列需再挪一列 |
| 起始行 | Sheet3 从第 2 行起（第 1 行是表头）；Sheet1 仍从第 1 行起，两边起始行不同是刻意的 |
| 结束行 | `5000` 按实际数据量改，B/C/G 三列必须同一结束行 |
| 同名列 | Sheet1 和 Sheet3 项目列都在 B 列，公式内均已带 `Sheet3!` 前缀，不会串 |
| 辅助列 | 老版本方案的 Z 列辅助列要建在 **Sheet3** 里，不是 Sheet1 |
