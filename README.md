# finance-tools

两个财务向的单文件工具。**双击用浏览器打开就能跑**，不装环境、不联网、数据不出本地。

---

## 1. 财务台账异常项检测工具

`finance-ledger-checker/财务台账异常项检测工具.html`

复制 Excel 里的台账区域，粘贴进去，点「检测异常」，结果当场出。

### 检测项

| 类别 | 规则 |
|---|---|
| 金额 | 金额为空 / 含非数字字符 / 千分位格式不规范 / 小数部分含逗号 / 含多个小数点 |
| 重复 | 按「项目名称 + 供应商」键比对，注明与第 N 条重复或首次出现共 N 条 |
| 供应商 | 为空 → 异常；名称已标准化 → 提示 |
| 日期 | 计划完成日期格式异常，直接报出是哪个值 |

金额额外输出一列**标准化金额**，统一写法后再比较。

结果分**异常项**和**提示项**两类：异常项是要改的，提示项自己判断。

> 实际使用：一批台账核对从 5 小时压到 2 小时。
> 省下的时间主要来自「把规则写清楚」，不是自动化本身。

### 输入列

```
序号 | 项目名称 | 项目编号 | 合同金额 | 供应商 | 计划完成日期
```

另会自动识别业务关键词：验收单、材料、垫资、变更、单一供方、工时、到期。

## 2. 财务分析报告生成器

`finance-report-generator/finance-report-generator.html`

录入三大报表科目，输出一份带图表的财务分析报告。

### 输入

资产负债表与利润表的主要科目：

```
资产总计 / 流动资产合计 / 货币资金 / 应收票据及应收账款 / 存货 / 固定资产
负债总计 / 流动负债合计 / 应付票据及应付账款 / 应付职工薪酬 / 应交税费
所有者权益合计 / 实收资本 / 未分配利润
营业收入 / 营业成本 / 销售费用 / 管理费用 / 研发费用
```

### 输出

- 核心指标计算（含 **杜邦分析**：ROE = 净利率 × 总资产周转 × 权益乘数）
- ROE 驱动因素拆解，附杜邦拆解图
- 趋势文字与多期对比
- 四大风格文字解读
- **风险预警清单**（如 ROE 为负、净利率低于 5% 安全线等会给明确提示）

## 3. 片段

`snippets/项目执行人合并公式.md`

Excel 单列原地公式，跨表按项目名称模糊匹配（VLOOKUP / LET / XLOOKUP）。
应对两边名称对不齐——多了字符、少了字符——的情况，**不新增辅助列**。

---

## 为什么不做成 Web 服务

因为要给同事用。说一句「你先装个环境」，这个工具就废了。

单文件意味着功能上要做取舍，这个取舍值得——**用不起来等于没做**。
